2. Страница каталога падает с HTTP 500 при NUL-символе в поиске
Приоритет: СРЕДНИЙ
Воспроизведение:
- GET /catalog?search=%00 возвращает HTTP 500.
- GET /ru/catalog?search=%00 также возвращает HTTP 500.
Ожидаемый результат: пустой результат либо контролируемый HTTP 400.
Проблема относится к серверному рендерингу каталога и отличается от уже
зафиксированной ошибки NUL в API поиска.
Связанный файл:
- app/(shop)/catalog/page.tsx

3. Страница статей падает с HTTP 500 при NUL-символе в фильтре категории
Приоритет: СРЕДНИЙ
Воспроизведение:
- GET /articles?category=%00 возвращает HTTP 500.
- GET /ru/articles?category=%00 возвращает HTTP 500.
Обычные неизвестные значения category=abc и category=missing возвращают HTTP 200,
поэтому ошибка возникает именно при передаче управляющего символа в фильтр.
Ожидаемый результат: пустой список либо контролируемый HTTP 400.
Связанный файл:
- app/(shop)/articles/page.tsx

4. API статей принимает categoryId=0 как корректный фильтр и скрывает все статьи
Приоритет: НИЗКИЙ/СРЕДНИЙ
Воспроизведение без авторизации:
- GET /api/articles?categoryId=0 возвращает HTTP 200 с data=[] и total=0.
- При отсутствии categoryId API возвращает опубликованные статьи.
- Отрицательное значение categoryId=-1 уже отклоняется HTTP 400, поэтому
  обработка нулевого идентификатора непоследовательна.
Ожидаемый результат: HTTP 400 для несуществующего/неположительного ID либо
явное трактование 0 как отсутствующего фильтра.
Связанный файл:
- app/api/articles/route.ts

1. Публичные list API возвращают HTTP 500 при значении page=Infinity
Приоритет: СРЕДНИЙ
Воспроизведение без авторизации:
- GET /api/questions?page=Infinity возвращает HTTP 500 без JSON-ответа.
- GET /api/reviews?page=Infinity возвращает HTTP 500.
- GET /api/pages?page=Infinity возвращает HTTP 500.
- GET /api/articles?page=Infinity возвращает HTTP 500.
Фактическая причина: общий разбор параметров принимает Infinity как число,
после чего бесконечное значение попадает в offset/limit запроса к базе данных.
Ожидаемый результат: HTTP 400 для нечислового/неограниченного значения либо
безопасная нормализация к допустимой странице.
Связанные файлы:
- lib/api/helpers.ts
- app/api/questions/route.ts
- app/api/reviews/route.ts
- app/api/pages/route.ts
- app/api/articles/route.ts
